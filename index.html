Cofrinho

App web de finanças pessoais · Mobile-first

  • HTML
  • CSS
  • JavaScript
  • Firebase Auth
  • Cloud Firestore
  • Chart.js
Contexto
Registrar entradas e saídas, acompanhar metas e entender para onde vai o dinheiro, direto do celular.
Solução
  • Lançamentos categorizados, com categorias personalizáveis
  • Despesas fixas mensais e compras parceladas
  • Metas com progresso visual
  • Gastos por categoria e comparativo dos últimos 4 meses
  • Navegação por mês e indicador de sincronização
Decisões técnicas
  • Sem servidor próprio: login com Google via Firebase Authentication
  • Dados isolados por usuário em users/{uid}/… no Firestore
  • Listeners onSnapshot atualizam a interface em tempo real
  • Zero build: um único arquivo com o SDK modular do Firebase via CDN
